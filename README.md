# self-study: Go で技術面接・アルゴリズム対策

Go で技術面接（コーディングテスト／ライブコーディング／技術質疑／システム設計）の対策をするための教材です。
アルゴリズムを**ほぼ初めて学ぶ人**を想定しています。

## 使い方

1. 各テーマの `README.md` を読む（解説）
2. `problems.go` の空の関数を実装する
3. テストで採点する

   ```bash
   go test ./algorithms/00_complexity/
   ```

   詳しく見たいとき（どのケースで失敗したか）は `-v` を付けます。

   ```bash
   go test -v ./algorithms/00_complexity/
   ```

   1問だけ採点したいときは `-run` で関数名を指定します。

   ```bash
   go test -v -run TestSumToN ./algorithms/00_complexity/
   ```

4. 15〜30分考えても分からなければ `solutions/` を見る
   見たあとは**何も見ずにもう一度書く**のが一番身につきます。

> 最初は全テストが失敗します（未実装なので正常です）。
