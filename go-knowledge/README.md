- goroutine と channel、`sync` パッケージ
- `context` の使い方
- エラーハンドリング（`errors.Is` / `errors.As` / ラップ）
- GC とメモリ（スタックとヒープ、エスケープ解析）
- `defer` / `panic` / `recover`
