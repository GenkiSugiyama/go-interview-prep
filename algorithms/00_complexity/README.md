# 00. 計算量（Big-O）入門

面接でコードを書いたあと、ほぼ必ず聞かれるのが
**「この解法の計算量（時間計算量・空間計算量）は？」** です。
まずはこの「ものさし」を身につけましょう。

## 計算量とは

入力のサイズ `n` が大きくなったとき、**処理の回数がどのくらいの勢いで増えるか**を表したものです。
細かい回数ではなく「増え方の形」だけを見ます。

```go
// n 回ループ → O(n)
for i := 0; i < n; i++ {
    sum += i
}
```

```go
// n × n 回ループ → O(n²)
for i := 0; i < n; i++ {
    for j := 0; j < n; j++ {
        count++
    }
}
```

### ルール

1. **定数倍は無視する**: `3n` 回でも `n/2` 回でも O(n)
2. **一番大きい項だけ残す**: `n² + n + 100` は O(n²)
3. **入力が複数あるなら別の文字で**: 配列 `a`（長さ n）と `b`（長さ m）を順に1回ずつ回すなら O(n + m)

## よく出てくる計算量（速い順）

| 計算量 | 名前 | 例 | n = 100万 のときの回数の目安 |
|--------|------|----|------------------------------|
| O(1) | 定数時間 | 配列の `a[i]`、map の参照 | 1 |
| O(log n) | 対数時間 | 二分探索 | 約 20 |
| O(n) | 線形時間 | 配列を1回なめる | 100万 |
| O(n log n) | | ソート（`sort.Ints`、`slices.Sort`） | 約 2000万 |
| O(n²) | 二乗時間 | 二重ループで全ペアを見る | 1兆（**間に合わない**） |
| O(2ⁿ) | 指数時間 | 全部分集合を試す | 計算不能 |

**目安:** コンピュータは1秒に約 1億（10⁸）回の単純な処理ができると考えます。
問題の制約が `n ≤ 10⁵` なら、O(n²) = 10¹⁰ では間に合わないので O(n log n) 以下を狙う、という判断に使います。

## O(log n) のイメージ

「毎回半分に減らす」と O(log n) になります。
100万 → 50万 → 25万 → … と半分にしていくと、約 20 回で 1 になります。

```go
for n > 1 {
    n /= 2 // 毎回半分 → O(log n)
}
```

## 空間計算量

**追加で使うメモリ**の量です。考え方は時間計算量と同じです。

```go
seen := make(map[int]bool) // 最大 n 個入る → 空間 O(n)
```

変数を数個使うだけなら空間 O(1) です。

## Go で計算量を意識すべきポイント

| 操作 | 計算量 | メモ |
|------|--------|------|
| `s[i]`（スライスの添字アクセス） | O(1) | |
| `append(s, x)` | 平均 O(1) | 容量不足時はコピーが起きるが、平均すると O(1) |
| `m[key]`（map の参照・追加・削除） | 平均 O(1) | |
| `len(s)`, `len(m)` | O(1) | |
| `slices.Contains(s, x)` | **O(n)** | 中で全要素を見ている |
| `strings.Contains(s, sub)` | **O(n) 程度** | ループの中で使うと重くなる |
| `slices.Sort(s)` | O(n log n) | |
| `s + t`（文字列連結） | O(len(s)+len(t)) | ループで連結するなら `strings.Builder` を使う |

**ありがちな落とし穴:** ループの中で `slices.Contains` を呼ぶと、見た目は1重ループでも O(n²) です。

## 確認クイズ

次のコードの時間計算量は？（答えは下に）

```go
// Q1
func q1(a []int) int {
    return a[0] + a[len(a)-1]
}

// Q2
func q2(a []int) int {
    total := 0
    for _, x := range a {
        total += x
    }
    for _, x := range a {
        total -= x / 2
    }
    return total
}

// Q3
func q3(a []int) int {
    count := 0
    for i := 0; i < len(a); i++ {
        for j := i + 1; j < len(a); j++ {
            if a[i] == a[j] {
                count++
            }
        }
    }
    return count
}

// Q4
func q4(n int) int {
    count := 0
    for i := 1; i < n; i *= 2 {
        count++
    }
    return count
}
```

<details>
<summary>答え</summary>

- **Q1: O(1)**。配列の長さに関係なく2回アクセスするだけです。
- **Q2: O(n)**。ループが2回で 2n 回ですが、定数倍は無視します。
- **Q3: O(n²)**。内側のループは n-1, n-2, … 回で、合計は約 n²/2 回です。1/2 は無視します。
- **Q4: O(log n)**。i が 1, 2, 4, 8, … と倍になるので、n に届くまで約 log₂ n 回です。

</details>

## 面接での答え方

計算量を聞かれたら、**理由もセット**で答えます。

> 「外側のループが n 回、内側も最大 n 回回るので、時間計算量は O(n²) です。
> 追加のメモリは変数だけなので、空間計算量は O(1) です。」
